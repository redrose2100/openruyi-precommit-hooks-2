# check-spdx-header

> Rule ID: `check-spdx-header`

## Original Requirement

Source: [openRuyi Packaging Guidelines · SPDX Copyright and License Declaration](https://www.openruyi.cn/en/docs/guide/packaging-guidelines#spdx-copyright-and-license-declaration)

> A spec file must start with SPDX-style copyright and license
> declarations, in the following format (`SPDX-FileContributor` is
> optional):
>
> ```spec
> # SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
> # SPDX-FileCopyrightText: (C) 2026 openRuyi Project Contributors
> # SPDX-FileContributor: Your Name <your.email@example.com>
> #
> # SPDX-License-Identifier: MulanPSL-2.0
> ```

## Checkpoints

| # | Checkpoint | Requirement | Failure condition |
| --- | --- | --- | --- |
| 1 | Declaration position | The file must start with SPDX declarations — the **first line** of the file must be an SPDX line (`SPDX-FileCopyrightText:`, `SPDX-FileContributor:` or `SPDX-License-Identifier:`); leading blank lines and leading comments are not allowed, and the header block may only contain SPDX declarations | File is empty, not UTF-8 encoded, starts with a blank line, does not start with a comment, starts with a non-SPDX comment, or contains a non-SPDX comment inside the header block |
| 2 | ISCAS copyright | Contains `# SPDX-FileCopyrightText: (C) <year> Institute of Software, Chinese Academy of Sciences (ISCAS)` (required) | Fails if missing |
| 3 | openRuyi copyright | Contains `# SPDX-FileCopyrightText: (C) <year> openRuyi Project Contributors` (required) | Fails if missing |
| 4 | Contributor attribution | `# SPDX-FileContributor: ...` (optional, zero or more lines) | Not part of the check |
| 5 | Separating blank line | **Exactly one** `#` blank comment line between the copyright block and the license line (required) | Fails if missing or more than one |
| 6 | License identifier | Contains `# SPDX-License-Identifier: MulanPSL-2.0` (required), and the license value must be the default `MulanPSL-2.0` | Fails if missing; fails if present but not the default `MulanPSL-2.0` |

### Year Formats

`<year>` in the two copyright lines supports the following formats
(regex: `\d{4}((,|-) \d{4})*`):

| Format | Example |
| --- | --- |
| Single year | `2026` |
| Comma-separated years | `2025, 2026` |
| Hyphenated year range | `2025-2026` |

Regex validation example:
`SPDX-FileCopyrightText: (C) \d{4}((,|-) \d{4})* <Organization>`

## Usage

Add to `.pre-commit-config.yaml`:

```yaml
-   repo: https://github.com/openRuyi-Project/openruyi-precommit-hooks
    rev: v0.1.0   # use the latest tag
    hooks:
    -   id: check-spdx-header
```

It can also be used as a standalone command:

```console
$ check-spdx-header path/to/foo.spec
```

An exit code of 1 means some files do not meet the requirements; 0 means
all files pass.

## Examples

### Pass ✅

```spec
# SPDX-FileCopyrightText: (C) 2025, 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
# SPDX-FileCopyrightText: (C) 2025, 2026 openRuyi Project Contributors
# SPDX-FileContributor: Zheng Junjie <zhengjunjie@iscas.ac.cn>
#
# SPDX-License-Identifier: MulanPSL-2.0

Name:           foo
```

### Fail ❌ (missing openRuyi copyright declaration)

```spec
# SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
#
# SPDX-License-Identifier: MulanPSL-2.0

Name:           foo
```

### Fail ❌ (leading non-SPDX comment)

The **first line** of the file must be an SPDX declaration; a leading
comment such as a generator banner is not allowed.

```spec
# generated by openruyi-tooling
# SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
# SPDX-FileCopyrightText: (C) 2026 openRuyi Project Contributors
#
# SPDX-License-Identifier: MulanPSL-2.0

Name:           foo
```

### Fail ❌ (leading blank line)

```spec

# SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
# SPDX-FileCopyrightText: (C) 2026 openRuyi Project Contributors
#
# SPDX-License-Identifier: MulanPSL-2.0

Name:           foo
```

### Fail ❌ (non-SPDX comment inside the header block)

```spec
# SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
# generated by openruyi-tooling
# SPDX-FileCopyrightText: (C) 2026 openRuyi Project Contributors
#
# SPDX-License-Identifier: MulanPSL-2.0

Name:           foo
```

### Fail ❌ (license is not MulanPSL-2.0)

```spec
# SPDX-FileCopyrightText: (C) 2026 Institute of Software, Chinese Academy of Sciences (ISCAS)
# SPDX-FileCopyrightText: (C) 2026 openRuyi Project Contributors
#
# SPDX-License-Identifier: MIT

Name:           foo
```

In this case the license line exists but is not the default `MulanPSL-2.0`,
and the error message points this out explicitly:

```
foo.spec: SPDX-License-Identifier must be the default license "MulanPSL-2.0" (found "MIT")
```
